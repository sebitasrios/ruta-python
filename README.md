# Python Learning Path 🐍

My personal path for learning Python, from the basics to backend development with a focus on security. Every folder has exercises I wrote while studying at ITM and on my own.

## 🚧 In progress: Backend with Python and Cybersecurity

[`backend-python-ciberseguridad/`](backend-python-ciberseguridad) is my current track. Its goal is to become a **Junior Backend Developer with a cybersecurity focus**, building practical skills in Python backend programming, APIs, databases, automated testing, version control and secure development. Exercises are added as I go; the first one is a user sign-up validator with unit tests.
